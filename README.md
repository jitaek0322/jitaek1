# ⚓ 군생활 관리 — 설치 안내

해군 복무 D-day · 휴가 · 급여/적금 · 일정 · 목표를 관리하고, **매일 18시에 아이폰 푸시 알림**을 받는 개인용 앱이에요.
모두 **무료**(GitHub + Firebase 무료 요금제)로 돌아가요.

> 💻 처음 설정은 **PC에서 하는 걸 추천**해요 (파일 업로드가 폰에선 불편해요). 30분 정도 걸려요.
> 설정이 끝나면 그 뒤로는 아이폰만 있으면 돼요.

---

## 전체 구조

```
아이폰 홈 화면 앱 (GitHub Pages)  ──저장──▶  Firebase (내 데이터)
                                                 ▲
GitHub Actions (매일 18:00 자동 실행) ──읽기──────┘ ──푸시──▶ 아이폰 알림
Scriptable 위젯 ──요약 읽기──▶ Firebase
```

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면 전체 |
| `logic.js` | D-day·복무율·진급·휴가·급여·적금 계산 + 알림 문구 |
| `firebase-config.js` | ⭐ **내 Firebase 값을 넣는 곳** |
| `firebase-messaging-sw.js` | 오프라인 지원 + 푸시 받기 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 아이콘·이름 |
| `notifier/send.js` | 매일 18시 알림 발송 프로그램 |
| `.github/workflows/daily-push.yml` | 발송 예약 (UTC 09:00 = 한국 18:00) |
| `firestore.rules` | 데이터 보안 규칙 |
| `widget/군생활관리-위젯.js` | 아이폰 위젯 (Scriptable) |

## 1단계. GitHub에 올리기

1. [github.com](https://github.com) 가입 → 오른쪽 위 **+ → New repository**
2. 이름: `navy-log` (아무거나 OK) · **Public** 선택 · Create
3. **uploading an existing file** 클릭 → 압축 푼 폴더 안의 **모든 파일·폴더를 끌어다 놓기** → Commit changes
   - `.github` 폴더는 숨김 폴더라 안 보일 수 있어요. 안 올라갔다면 **Add file → Create new file**에서 파일 이름 칸에 `.github/workflows/daily-push.yml` 을 입력하고 내용을 붙여넣으세요.
4. 저장소 **Settings → Pages** → Source: `Deploy from a branch` · Branch: `main` / `(root)` → Save
5. 1~2분 뒤 `https://내아이디.github.io/navy-log/` 주소가 생겨요. **이 주소를 메모해두세요.**

## 2단계. Firebase 만들기

1. [console.firebase.google.com](https://console.firebase.google.com) → 구글 계정 로그인 → **프로젝트 추가** (애널리틱스는 꺼도 돼요)
2. 프로젝트 홈에서 **웹 앱 추가 `</>`** → 이름 `군생활` → 등록
3. 화면에 나오는 `firebaseConfig = { apiKey: ..., ... }` 값을 **`firebase-config.js`의 같은 이름 칸에 복사**
4. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명 → 사용 설정**
5. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
   - 만든 뒤 **규칙** 탭 → 내용을 지우고 `firestore.rules` 파일 내용 붙여넣기 → 게시
6. ⚙️ **프로젝트 설정 → 클라우드 메시징 → 웹 구성 → 웹 푸시 인증서 → 키 쌍 생성**
   - 나온 긴 키를 `firebase-config.js`의 `FIREBASE_VAPID_KEY`에 붙여넣기
7. 수정한 `firebase-config.js`를 GitHub 저장소에 다시 업로드 (같은 이름이면 덮어써져요)

> `apiKey`는 공개돼도 괜찮은 값이에요. 데이터는 5번의 보안 규칙이 지켜줘요.

## 3단계. 알림 발송기 연결 (GitHub Secrets)

1. Firebase ⚙️ **프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성** → JSON 파일 다운로드
   - ⚠️ 이 파일은 비밀번호 같은 거예요. **저장소에 올리지 마세요.**
2. GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `FIREBASE_SERVICE_ACCOUNT`
   - Secret: JSON 파일을 메모장으로 열어 **내용 전체** 붙여넣기 → Add secret
3. 저장소 **Actions** 탭 → "I understand… enable" 버튼이 보이면 눌러서 켜기

## 4단계. 아이폰에 설치 + 알림 켜기

1. 아이폰 **Safari**로 1단계 주소 열기 (iOS 16.4 이상 필요)
2. 하단 **공유 버튼(□↑) → 홈 화면에 추가 → 추가**
3. 홈 화면의 ⚓ **군생활** 아이콘으로 앱 열기 (Safari 말고 꼭 아이콘으로!)
4. 상단 오른쪽이 🟢 **동기화됨** 이면 Firebase 연결 성공
5. **설정 탭 → 🔔 알림 켜기 → 허용**
6. 받을 알림 항목을 스위치로 골라주세요

## 5단계. 테스트 알림 보내기

GitHub 저장소 **Actions → 매일 18시 알림 → Run workflow → (테스트 알림 체크) → Run workflow**
→ 1분쯤 뒤 아이폰에 "⚓ 테스트 알림"이 오면 끝! 이제 매일 18시에 자동으로 와요.

## 6단계. 홈 화면 위젯 (Scriptable)

1. App Store에서 **Scriptable** 설치 (무료)
2. 군생활 앱 **설정 → 위젯 연결 키 만들기 → 값 복사**
3. Scriptable 열기 → 오른쪽 위 **+** → `widget/군생활관리-위젯.js` 내용 전체 붙여넣기
   - 맨 위 `PROJECT_ID`, `API_KEY`, `WIDGET_KEY` 세 줄을 복사한 값으로 바꾸기 → 이름을 `군생활`로 저장
   - ▶ 실행하면 미리보기가 떠요
4. 홈 화면 길게 누르기 → 왼쪽 위 **+** → **Scriptable** → 중간 크기 추천 → 추가
5. 추가된 위젯 길게 누르기 → **위젯 편집 → Script: 군생활**
   - 잠금 화면 위젯도 같은 방법으로 추가할 수 있어요 (원형·직사각형·한 줄)

> 🔤 위젯도 Pretendard로 보이게 하려면: 함께 든 `fonts/위젯용/` 폴더의 .otf 4개를 아이폰으로 옮긴 뒤, App Store의 글꼴 설치 앱(예: iFont)으로 설치하세요. 설치 안 하면 아이폰 기본 글꼴로 표시돼요. 앱 화면은 Pretendard가 내장돼 있어서 따로 설치할 필요 없어요.

> 🎨 위젯 테마(지게차·닻·미니멀·라이트)는 앱 **더보기 → 설정 → 위젯 테마**에서 고르면 위젯에 자동으로 반영돼요.

> 위젯의 "다음 출타·다음 일정"은 앱을 열 때 갱신돼요. D-day·복무율은 위젯이 알아서 계산해요.

## 기능 한눈에 보기

| 탭 | 기능 |
|---|---|
| 홈 | 전역 D-day · 지게차 진행 표시 · 진급/출타/봉급/휴가 · 남은 짬밥·주말·월급날 환산 · 오늘의 기분 · 다가오는 기념일 · 과실 경고 |
| 출타 | 연가·포상·위로휴가 잔여(위로휴가는 주말근무 마일리지 자동 적립) · 평일/휴일/면회외출 횟수 · 출타 플래너(교통편·만날 사람·체크리스트·쓴 돈) |
| 돈 | 급여·적금 / 가계부(봉급 − 적금 − 지출 = 남은 돈, 하루 사용 가능 금액, 분류별) |
| 일정·목표 | 달력 일정 · 매일 체크 목표 |
| 더보기 | 운행 일지 · 체력 기록 · 한 줄 일기 · 상벌·주말근무 · 생일·기념일 · 업적 배지 · 월간 리포트 · 설정 |

**주말근무 마일리지 규칙 (하루 합계)**: 0~4시간 → 양호 1점/시간, 4~8시간 → 위로 마일리지 1점/시간, 8시간 초과 → 인정 안 함. 위로 마일리지 10점 = 위로휴가 1일 (설정에서 변경 가능).
**과실 경고**: 최근 2개월 안에 받은 과실 횟수를 세서 2회면 주의, 3회면 진급 누락 경고를 띄워요.

| 항목 | 언제 오나요 |
|---|---|
| 매일 복무 현황 | 매일 — 전역 D-day · 복무율 · 계급 |
| 일정 리마인드 | 내일 일정 / 오늘 18시 이후 일정 (일정마다 전날·당일·둘 다·없음 선택) |
| 진급 알림 | 진급 7일 전 · 전날 · 당일 |
| 휴가 · 외출 | 출발 3일 전 · 전날 · 복귀 당일 |
| 목표 체크 | 오늘 체크 안 한 목표가 있을 때 |
| 적금 납입일 | 납입일 전날 · 당일 |
| 복무 기념일 | 복무율 25·50·75%, 전역 100·50·30·10·1일 전 |
| 생일 · 기념일 | 등록한 생일·기념일 전날 · 당일 |
| 일기 리마인드 | 오늘 일기를 안 썼을 때 (기본 꺼짐) |
| 과실 경고 | 최근 2개월 과실이 2회 이상이 된 날, 줄어든 날 |
| 월간 리포트 | 매월 1일 — 지난달 운행·지출·양호·기분 요약 |

## 자주 묻는 것

- **알림이 18시 정각에 안 와요** → GitHub 예약 실행은 서버 사정으로 10~30분 늦을 수 있어요.
- **알림이 아예 안 와요** → ① 홈 화면 아이콘으로 열었는지 ② 아이폰 설정 → 알림 → 군생활 허용 ③ Actions 탭 실행 기록에 빨간 ✕가 있는지 확인. 빨간 ✕면 로그를 캡처해서 물어봐 주세요.
- **60일 지나면 멈춘다던데?** → 발송기가 50일마다 자동으로 빈 커밋을 남겨서 계속 돌아가게 해놨어요.
- **데이터가 사라질까 걱정돼요** → Firebase에 자동 저장되지만, 아이폰에서 앱을 지우면 익명 계정이 바뀌어 연결이 끊겨요. **설정 → 백업 → 내보내기**를 가끔 해두세요.
- **진급일이 달라요** → 일병·병장 날짜는 추정값이에요. 설정 → 복무 정보에서 부대 공지대로 고치세요.
- **봉급 기준** → 2026년 병 기본봉급 (이병 75만 · 일병 90만 · 상병 120만 · 병장 150만). 적금은 월 최대 55만 원, 만기 시 정부가 원금의 100%를 지원해요. 이자는 단리로 대략 계산한 값이에요.
